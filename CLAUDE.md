# Конкурентный срез — правила для ИИ-помощника

Дашборд «Конкурентный срез» (разделы «Предложение» и «Сделки»), публикуется через GitHub Pages:
https://aleksey-lyapin.github.io/konkurentny-srez/

Сайт — файл `index.html`, но он **собирается автоматически** (GitHub Actions, каждый день) из `template.html` и данных. **Правки вёрстки и логики вноси в `template.html`** (при необходимости повтори их в `index.html`, чтобы они появились до следующей сборки), иначе их сотрёт автосборка. **Файлы правят несколько человек**, поэтому:

1. **Перед любой правкой** выполни `git pull` и работай с файлом из этого репозитория. Не бери `index.html` из другой папки, чата или старой копии и не заливай его поверх: так стираются чужие правки.
2. Меняй только то, о чём просят. Не переписывай файл целиком и не откатывай чужие изменения, даже если они выглядят лишними. Если сомневаешься, спроси.
3. Перед `git push` посмотри `git diff` и убедись, что в нём только твои правки. Если `push` отклонён, сделай `git pull --rebase` и повтори. Не используй `--force`.
4. В сообщении коммита кратко напиши по-русски, что изменилось, например «Сделки: …», «Шапка: …».

## Договорённости, которые нельзя терять

- Наверху две постоянные кнопки разделов: «Предложение» и «Сделки».
- По умолчанию (ссылка без `#`) открывается раздел «Сделки»: `const dealsHash = !initialG || …`.

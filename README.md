# Конкурентный срез

Дашборд BAZA Development по Екатеринбургу: предложение конкурентов и сделки.
Сайт: https://aleksey-lyapin.github.io/konkurentny-srez/

## ⚠️ Файл правят несколько человек

Весь дашборд — один файл `index.html`. Чтобы не стирать правки друг друга:

1. **Перед началом работы скачайте свежую версию** (`git pull`) и правьте именно её.
2. **Не заливайте `index.html` из другой папки или старой копии** поверх файла в репозитории: все чужие изменения, сделанные с тех пор, пропадут.
3. Если работаете через ИИ-помощника, начните с фразы: «сначала скачай последнюю версию из репозитория и правь её». Правила для Claude лежат в `CLAUDE.md`.

После отправки на GitHub сайт обновляется сам за 1–2 минуты.
